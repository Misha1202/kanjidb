# Перераспределение нагрузки ПВЗ

Инструмент: загрузите Excel с офисами ПВЗ, разметьте сильные/слабые ячейки (1-й и 2-й уровень) и пересчитайте расстановку офисов внутри каждого квадрата.

## Файлы

| Файл | Назначение |
|------|-----------|
| `index.html` | Разметка страницы (сетка, таблица, модалка уровней) |
| `script.js` | Логика: чтение XLSX, агрегация, ядро перестановки, экспорт |
| `style.css` | Стили (светлая/тёмная тема автоматически) |

## Шаблон Excel

Колонки: **Адрес** (адрес ПВЗ), **Квадрат**, **Ячейка** (1–…), **Кол-во коробок**. Колонки определяются автоматически, вручную можно переопределить в блоке «Колонки определены неверно?».

## Как это работает

1. Данные агрегируются по связке квадрат + ячейка + адрес.
2. Сетка: 3×3-группы, нумерация сверху вниз (1 4 7 / 2 5 8 / 3 6 9).
3. Разметка уровней: режим «1-й уровень» / «2-й уровень» + клик по ячейке. Уровни общие для всех квадратов.
4. «Пересчитать»: самые сильные офисы (по коробкам) ставятся в ячейки 1-го уровня, самые слабые — во 2-й.
5. Экспорт: отчёт по текущему квадрату или по всем КС одним листом (сводка + детализация).

## Экспорт «Все КС»

- **1 · Ко всем КС** — уровни применяются к каждому квадрату (пересчёт отдельно).
- **2 · Только к выделенному** — пересчитан только выделенный квадрат, остальные как в исходном файле. Сводка в отчёте показывает фактические уровни каждого квадрата.
